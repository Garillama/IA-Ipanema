# Operaciones siguientes, separadas y todavía no autorizadas

## A. Cerrar dos estados comerciales con evidencia oficial

Opción sin nuevas llamadas del agente: el propietario proporciona para cada URL el resultado oficial de Inspección de URLs, conservando fecha, cobertura/motivo, canonical declarado y seleccionado por Google, permisos, último rastreo y origen de la observación:

- https://rhino-performance.com/terapia-fria/
- https://rhino-performance.com/productos/brazo-presoterapia-pro-3-individual/

Alternativa, solo mediante autorización específica posterior: dos inspecciones de lectura con la integración existente y credencial autorizada disponible. Primero verificar disponibilidad de esa integración sin extraer credenciales. No iniciar OAuth, prueba en vivo del storefront, Solicitar indexación ni Validar corrección como parte de esa lectura. Si no hay credencial disponible, conservar la vía de exportación manual. No existe ejecución nueva autorizada por este documento.

Propósito: aclarar el estado oficial de estos dos destinos, no demostrar por sí solo una carencia editorial. No repetir las quince inspecciones históricas.

## B. Resolver el destinatario de consultas comerciales

Con el filtro de consulta exacta, exportar Páginas para «presoterapia brazos», «botas de presoterapia» y «botas de presoterapia precio», manteniendo fecha, tipo de búsqueda y segmentos. Esto permite evaluar qué landing sirve cada intención y si hay un conflicto real. Una categoría ya recibe esas consultas, pero no conocemos la distribución entre todas las landings.

Confirmar el operador exacta/contiene de las dos exportaciones entregadas. No es necesario volver a exportar todo si el propietario puede confirmar ese metadato. Las tablas marginales no se cruzan para inventar consultas mexicanas móviles.

## C. Cualquier lectura HTTP de rutas históricas

Las cinco redirecciones originales permanecen en el alcance anterior [pendiente](../opportunities-20261113/redirect-read-scope.md). Las rutas de los nuevos ejemplos 404 con tráfico son otra población: no agregarlas automáticamente a ese manifiesto, no reutilizar autorizaciones consumidas.

Antes de solicitar ejecución: seleccionar el mínimo de destinos, identificar el mecanismo real y comprobar compatibilidad con los presupuestos existentes. Preparar manifiesto, hash, comando existente válido, marcador único, supervisor y autorización exacta. No se crea otro crawler ni se cambia su límite. No hay comando preparado o ejecución autorizada para esta población.

Sin respuesta actual y destino equivalente demostrado no existe un parche301 listo para publicar. Para PDF se necesita además el documento oficial y versión correcta, sin sustituir productos o instrucciones.

## D. Edición o publicación

Ninguna propuesta de este paquete está lista para publicar. La guía de selección de Presoterapia necesita demostrar una carencia útil y datos comerciales verificables; los metadatos necesitan evidencia específica de presentación e intención. Cualquier diff posterior requerirá revisión independiente, QA, respaldo, hashes y autorización específica del propietario.
