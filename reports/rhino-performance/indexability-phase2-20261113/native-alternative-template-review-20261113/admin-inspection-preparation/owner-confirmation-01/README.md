# Confirmación administrativa del propietario — 01

Se registra la confirmación del propietario de que el selector de Categoría muestra Crear plantilla y la plantilla base se llama Categoría. La imagen no está adjunta en este mensaje: se conserva el testimonio, sin afirmar inspección visual independiente ni inventar un archivo o hash de captura.

El ADR se modifica solo mediante una anotación de estos hechos, con su preimagen conservada. Permanece needs_evidence, sin autorización de implementar, crear, guardar, asignar o publicar. La existencia de la plantilla base no prueba que Presoterapia la tenga asignada.

## Siguiente comprobación

Desde el selector ya identificado, abrir únicamente el formulario de creación si el control abre un diálogo sin crear la plantilla. No completar Nombre ni confirmar Crear. Mostrar la lista Crear desde sin elegir otro valor y conservar una captura donde se vean el formulario, las opciones de origen y el botón final. Comprobar si aparece Categoría como origen. Cerrar sin confirmar.

Si el control crea inmediatamente, hay autoguardado o el efecto es ambiguo, detenerse antes de pulsarlo. Una lista de orígenes solo confirma disponibilidad de copia: no demuestra copia realizada o fidelidad de configuración. Si no aparece el campo esperado, conservar la pantalla sin cambiar la interfaz para forzar el resultado.

Cuando se aporte la captura, se podrá revisar directamente y continuar el contraste incremental de la evidencia nueva. No se ha accedido a Tiendanube ni ejecutado una operación remota.
