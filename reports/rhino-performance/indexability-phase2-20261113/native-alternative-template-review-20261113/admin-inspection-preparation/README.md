## B. Ver las alternativas en el editor

Abrir Tienda online > Diseño > Editar diseño del diseño publicado. En el selector de plantillas elegir el tipo Categoría y examinar la lista, sin alterar asignaciones. Identificar por nombre la plantilla registrada para Presoterapia en el paso A. No asumir que la base es la usada por esa categoría.

**Captura B:** selector abierto, tipo Categoría, nombres de la plantilla base/alternativas, opción Crear plantilla y contadores visibles. Incluir la identidad del diseño si aparece, ocultando datos personales.

El contador informa cuántas entidades usan una plantilla, no cuáles son. Para saber si hay otras categorías asignadas se requiere la lista nominal que permita el administrador, o revisar sus fichas. Si esa evidencia no está disponible, el alcance total queda desconocido. Tener las cinco categorías públicas comprobadas no certifica el inventario administrativo completo.

## C. Ver si puede copiar la configuración correcta

La guía oficial distingue abrir el diálogo de creación de confirmar Crear. Si el botón de apertura únicamente muestra ese diálogo, se puede inspeccionar sin introducir nombre ni confirmar nada. Si en esta versión el control crea inmediatamente, anuncia autoguardado o su efecto es ambiguo, no pulsarlo: enviar la captura B y dejar pendiente este paso.

En el diálogo, abrir únicamente la lista de Crear desde, sin seleccionar una opción distinta ni completar campos. Comprobar si aparece el nombre exacto de la plantilla registrada para Presoterapia. Cerrar el diálogo con su control de cierre; no confirmar Crear.

**Captura C:** diálogo y lista de orígenes disponibles, de modo que pueda relacionarse el nombre con la captura A. La presencia del origen demuestra disponibilidad de copia; no demuestra una copia fiel ya realizada.

Si abrir el diálogo no está claramente permitido por el comportamiento de esa interfaz, detenerse. Ninguna creación se autoriza por este procedimiento.

## D. Revisar orden y disponibilidad del texto enriquecido

En la plantilla actualmente usada por Presoterapia, observar la lista de secciones existente sin arrastrar, insertar o activar ninguna. Identificar el listado de productos y las secciones que lo siguen. Mantener heading desactivado.

Si existe un catálogo de secciones consultable sin insertar, abrirlo y buscar texto enriquecido/editorial. No elegir el elemento que lo añade.

**Captura D2:** opción de texto enriquecido disponible. Si abrir la lista inserta automáticamente un bloque, no hacerlo. Observar una opción no prueba todavía que pueda colocarse después del listado.

Si ya existe un bloque de texto enriquecido en una plantilla, abrir solo su panel de configuración. Observar si la barra ofrece encabezado de nivel2 y enlaces; no aplicar formatos, editar texto o crear enlaces.

**Captura D3:** controles de formato del bloque existente, mostrando la posibilidad de H2 y vínculo cuando sean visibles. Si no hay bloque existente, registrar pendiente en vez de insertar uno para probarlo. Un control visual H2 no acredita el HTML final; esa comprobación requiere renderizado posterior autorizado.
