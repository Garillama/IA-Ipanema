# Decisiones antes de implementar

Fecha: 2026-11-08. El orden se propone en el [roadmap](../11-opportunities/roadmap.md), y las opciones se fundamentan en [preguntas al propietario](questions-for-owner.md).

| Tema | Recomendación inicial | Qué falta para concretarla |
|---|---|---|
| Alcance del siguiente lote | Accesibilidad/overflow y coherencia de catálogo | Pedido de implementación específico; este turno es discovery |
| Layout reutilizable | Configuración y variantes del componente actual | Diseño final y alcance global o por instancia |
| Paginación | Enlaces reales siempre; elegir classic o enhancement según UX necesaria | Requisito comercial y prueba del cursor real |
| Medios | Un helper compartido, prioridad de LCP y sizes reales | Assets finales desktop/mobile y calidad objetivo |
| Semántica de PDP | Corregir HTML importado de descripción | Autoría y revisión de contenido del catálogo |
| Distribución multitienda | Patrones y código propio versionado | Permisos de implementación del tema y mecanismo de actualización |
| Validación comercial | Escenarios controlados con límites concretos | Cuenta/productos/operaciones de prueba autorizados |
| Lanzamiento | Repetir checks sin sesión y preparar publicación revisable | Momento y autorización explícitos del propietario |

No hace falta aprobar archivos de documentación ni decisiones técnicas rutinarias para leer y mantener esta base. Tampoco hay un watcher o proceso que publique al aceptar una propuesta.
